プライバシーポリシー

本ページは、Tournament（以下「本サービス」）における情報の取扱いについて説明します。

1. 取り扱う情報

本サービスの機能に応じ、Google認証に伴うユーザー識別情報、YouTubeチャンネルID・チャンネル名、対象配信の動画ID・ライブチャットID、参加登録・勝利報告に関連するチャットのメッセージIDや表示名、大会情報・参加履歴・認証に関する情報を取り扱います。

2. 利用目的

ログイン・主催者確認、YouTube LIVEへの接続確認、参加登録、勝利報告の照合、大会の進行管理、不正な重複処理の防止、問い合わせへの対応に利用します。

3. 外部サービス

本サービスはYouTube API Services（YouTube Data API）、Google認証、Supabaseを使用します。GoogleおよびYouTubeから取得する情報は、各サービスの規約・ポリシーの適用対象です。

Googleプライバシーポリシー ／ YouTube利用規約

4. 情報の共有

大会の表示・進行に必要な範囲で、参加者の表示名、対戦結果、大会情報などが他の利用者に表示される場合があります。認証およびデータベース処理にはSupabaseを利用します。本サービスで取り扱うGoogle・YouTube由来の情報は、前述の機能を提供するために利用します。

5. 保持期間・削除

大会情報および参加履歴は、大会の運営・履歴表示に必要な期間保持します。大会の終了・非表示・削除に関する処理は、サービス側の大会管理ルールに従います。YouTube API Servicesから取得した情報は、適用されるYouTube API Servicesの保存・更新・削除ルールに従って取り扱います。

Google・YouTubeへのアクセス権は、Googleアカウントのサードパーティ接続管理から取り消せます。ログアウトとGoogle側のアクセス権の取り消しは別の操作です。Google側でアクセス権を取り消しても、本サービス内に保存済みのデータが直ちに削除されるとは限りません。

保存データの削除を希望する場合は、連携解除・データ削除案内に記載した窓口へご連絡ください。大会開催中も申請を受け付けます。運営者が必要な本人確認を行い、管理者専用の非公開画面等で対象情報を確認・削除します。YouTube API Servicesを通じて取得・保存した本人に関するデータの削除申請については、可能な限り速やかに、遅くとも申請から7暦日以内に対応します。Google側での認可取り消しに伴うデータの削除についても、YouTube API Servicesの規定に従います。

本サービスの保存データを削除しても、YouTube上に保存された動画やライブチャットは削除されません。YouTube上のデータはYouTubeのサービスから管理してください。
